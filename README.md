# DSK309 — legacy script archive

This repository was retired on 23 October 2026.

DSK309 laboratories are supplied ready to use, with **Desolabs App**, **kind** and the compiled exercises already installed in the student VM. Open the app and select Start, Restart or Cleanup; no repository download is required.

Course preparation sources and live verification tests are maintained in [desolabs-app-kind-scripts/DSK309](https://github.com/desotech-it/desolabs-app-kind-scripts/tree/main/DSK309). See the [DSK309 course](https://github.com/desotech-it/DSK309) for the current laboratory instructions.

This archive preserves the historical binary distribution for compatibility with earlier course editions.
